## Annotation

> DynamicTextAnchors (DTA) is a TypeScript library for creating resilient text anchors that can be reliably relocated even after a document has been modified. The library is designed around a generic tree abstraction, making it independent of any particular document model (DOM, XML, Markdown, etc.).

> **A note on project history**  
> DynamicTextAnchors originated as a graduation thesis focused on algorithms for persistent text anchoring in static and dynamic documents. The current project is a complete redesign of both the architecture and implementation, aiming to provide a simpler, more generic, and more extensible library.
>
> The original implementation and thesis materials are preserved in the [`thesis-legacy`](/thesis-legacy/) directory for historical reference and are no longer maintained as part of the current project.
